# 🧡 ONG União Alegre – Projeto HTML + CSS (Entrega 2)

## 🌍 Descrição do Projeto
Este repositório apresenta a **segunda entrega** do projeto da ONG União Alegre, desenvolvido como parte da disciplina de Desenvolvimento Web.  
Nesta etapa, foi aplicada a linguagem **CSS3** para estilizar a estrutura HTML criada na Entrega I, transformando-a em uma **interface moderna, responsiva e acessível**.

---

## 🎯 Objetivos da Entrega
- Implementar **design system completo** com variáveis de cor, tipografia e espaçamento modular.  
- Criar **layout responsivo** utilizando **Flexbox** e **Grid**.  
- Desenvolver **menu de navegação interativo e adaptável** (desktop e mobile).  
- Estilizar formulários, botões e cards de projetos de forma coerente e visualmente atrativa.  
- Garantir **acessibilidade** e **usabilidade** em diferentes tamanhos de tela.

## 🎨 Design System
- **Cores Primárias:** Azul escuro `#063970` e Azul intermediário `#0b4d8f`  
- **Cores Secundárias:** Branco, Cinza claro e tons neutros para contraste  
- **Tipografia:** *Segoe UI*, *Arial*, *sans-serif*  
- **Espaçamentos Modulares:** 8px, 16px, 24px, 32px, 48px, 64px  
- **Componentes:** Cards, botões interativos, formulários e navegação responsiva  

---

## 🖥️ Recursos Implementados
- Layout principal em **CSS Grid**  
- Componentes internos com **Flexbox**  
- Navegação **responsiva e interativa**  
- Sistema de **cards dinâmicos** para exibição dos projetos  
- **Formulário estilizado e acessível** com campos validados visualmente  
- Efeitos de **hover**, **focus** e **transições suaves**

---

## 📱 Responsividade
O design foi adaptado para **5 breakpoints principais**, garantindo boa experiência de uso em:
- Smartphones  
- Tablets  
- Laptops  
- Monitores widescreen  
- Dispositivos de alta densidade de pixels

---

## 👨‍💻 Tecnologias Utilizadas
- **HTML5**  
- **CSS3 (Flexbox e Grid)**  
- **Acessibilidade básica (ARIA, contraste e hierarquia visual)**
